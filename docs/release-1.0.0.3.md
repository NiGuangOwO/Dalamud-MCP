# Dalamud MCP 1.0.0.3

- 新增 `set_addon_checkbox`，通过原生组件接口设置复选框状态，并通知所属窗口。提供只读预检、期望原状态检查和重复请求不产生输入的行为。
- `click_addon_element` 现在拒绝把普通窗口点击误当成复选框状态切换，并指向专用工具，避免报告点击成功但组件状态未变化。
- 使用有界 ULD 数组和完整结构读取校验组件类型、所有权、可见性、启用状态及通知事件。拒绝有歧义的节点和非布尔参数。
- 同步开发指引。当前共 110 个工具，其中 66 个只读、44 个可变更。

Debug/Release 构建及相关离线检查通过；有限现场验证确认复选框实际勾选、后续按钮启用，重复设置没有再次通知。未使用 computer use。客户端可能需要重新连接 MCP 以刷新工具目录。
