# Dalamud MCP 1.0.0.5

- 战斗记录改为默认后台持续运行：登录后自动等待战斗，退出登录暂停并封场，重新登录恢复；无默认倒计时，不依赖 MCP 客户端或监听器。保留变更工具主闸门。
- 每场结束在独立后台线程将紧凑 JSON 保存为 `combat-recordings/auto/*.json.gz`，以临时文件后原子替换方式写入。自动清理至 7 天、1000 场和总计 100 MiB；待写队列最多 4 场，溢出和 IO 失败可查询。
- 历史场次可在重载后通过列表和分页读取工具访问；解压在游戏线程外执行并限制大小。新增持久开关及中英文设置说明；相同的持续配置请求不会中断当前场次。仍可显式选择有期限的临时采集。
- 无战斗时不生成记录文件，空闲且无动作时不扫描完整对象表。压缩、自动写盘及文件清理不在游戏线程执行。

Debug/Release 构建零警告零错误；CombatRecordingTest 23/23、归档测试 20/20、PluginLoadTest 121/121、ProtocolSmokeTest 50/50。覆盖读取边界、后台写入、压缩分页、重载、年龄/数量/字节清理、队列满和写盘失败；加载测试确认监听器停止不取消后台观察，卸载解除所有框架订阅。
