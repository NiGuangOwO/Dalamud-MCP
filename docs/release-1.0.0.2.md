# DalamudMCP 1.0.0.2

本次更新改善原生界面操作、运行时诊断和 IPC 查询，并修复命令文本被误发到聊天频道的问题。

- 修复 `SelectString` 菜单选项序号及列表激活行为，拒绝有歧义的选项匹配，并限制列表节点查找范围。
- IPC 支持严格的字符串参数及可空布尔返回，拒绝隐式参数转换。
- 新增只读工具 `get_addon_native_dispatch`，在可识别的 Dalamud 生命周期虚表包装下解析原始处理器地址，辅助原生路径分析。
- `click_addon_when_node_matches` 新增局部旋转角范围匹配，保留逐帧状态检查、单次输入、实例替换和超时保护。
- `send_chat` 拒绝以斜杠开头的文本及换行/NUL；游戏和插件命令应使用 `slash_command`。
- 同步开发指引和发布流程。当前目录包含 109 个工具，其中 66 个只读、43 个可变更。

相关改动已在国服客户端开发过程中进行有限的游戏内验证，并提供菜单、原生读取、几何匹配、IPC 和聊天输入的离线回归检查。发布构建另行完成 Debug/Release 构建及插件加载检查；离线检查不代表所有游戏状态均已现场验证。工具参数有变化，MCP 客户端可能需要重新连接以刷新 schema。

本次发布包含 DalamudMCP 服务端插件，不包含独立的金碟小游戏助手。
