# 地图状态与静态图标

`get_map_state` 是只读工具，从当前客户端的 `AgentMap` 读取当前与选中的地图/区域 ID、缩放参数、偏移和静态图标。

```json
{"markerOffset":0,"maxMarkers":40}
```

按 `nextMarkerOffset` 翻页；每页重新核对 `selectedMapId`，不要把地图切换前后的页拼成一份结果。默认返回 40 条，最多 132 条，参数必须是范围内的 JSON 整数。静态图标数超过安装 SDK 的容量时返回 `scanIncomplete=true`，不越界读取。

`mapVisible` 和 `mapReady` 描述 AreaMap 窗口。窗口关闭后地图代理仍可能保留上次选择，此时不能把缓存选择当作屏幕上正在显示的地图。`currentMapId` 与 `selectedMapId` 含义不同，选中另一张地图不会移动角色。

图标返回原生数组下标、图标 ID、数据类型/键和可选的原生 `subtext`。文字最多读取 512 字节，无法安全读取或在上限内找不到 NUL 时返回 null；原生文字可能含 SeString 控制数据。没有文字并不代表图标不存在。数据键保留 SDK 原值，工具不猜测其代表的 Excel 表。

`nativeX/nativeY` 是 SDK `MapMarkerBase.X/Y` 的原始有符号坐标，**不是世界坐标，也不是玩家可见的地图坐标**，不能直接传给移动工具。此列表仅覆盖静态图标，不覆盖全部任务、动态物体、旗标和临时标记，也不提供图标点击或传送。

验证：离线合成内存覆盖当前/选中地图区分、分页、坐标符号、无效指针、字符串边界和数组容量。游戏内读取利姆萨下层甲板地图，观察到 63 个静态图标；两页读取无重复，区域出口与地图窗口文字一致。关闭地图后 `mapVisible=false`。其他地图、动态标记及图标交互不在本次验证范围。
