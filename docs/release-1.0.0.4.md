# Dalamud MCP 1.0.0.4

- 新增五个 `combat_recording_*` 工具：启停、状态、场次列表、分页技能时间线、JSON 导出。进战自动开场、脱战自动结算，保留开怪技能。
- 从安装 SDK 的服务端 ActionEffect 接口复制有界技能效果，保留原始字段并解码直接伤害/治疗、暴击/直击；支持自身/宠物及全部附近动作范围，补充读条、状态和死亡状态采样。
- 默认关闭，启用受变更闸门限制；有超时、队列、事件数量、JSON 字节预算、场次数量和导出文件保留上限。退出登录、停止服务和卸载清理钩子，截断及丢包明确报告。
- 当前共 115 个工具，其中 70 个只读、45 个可变更。同步中英文说明、服务端指引及开发技能路由。

验证：Debug/Release 构建零警告零错误，CombatRecordingTest 23/23、PluginLoadTest 116/116、ProtocolSmokeTest 50/50。原生读取在独立进程覆盖无效、短读、跨页及 32/33 目标边界。

有限现场测试：仅通过 Dalamud-MCP 进入 90 级木人歼灭战，手动使用热分裂弹，随后由原有自动循环继续。捕获 158334ms、306 条事件，其中 215 条技能效果、19 种动作；开怪技能位于进战前 774ms，自动以 `combat_exit` 封场，无事件丢弃、无无效包或队列丢包。测试逻辑构建 MVID 为 `8bb606b4-e006-4245-8fde-676b98ff612b`；最终构建另补导出/状态中的构建标识及指引，发布前再次核对其运行 MVID。

范围限制：不提供完整 FFLogs 功能、周期 DoT/HoT 跳伤归因或上传；宣告效果不等于实际有效伤害/治疗。记录为内存数据，重载前需导出。`all` 范围、治疗实战、多目标及大型队伍性能尚未现场验证。详见[战斗记录说明](combat-recording.md)。
